# Have You Tried Turning It Off?

A program that writes exactly one line to `/output/entry.txt` — the funny single-line reply a hopeless tech support agent gives a desperate customer. Built for the make.fun competition **"Have You Tried Turning It Off?"** (`u-motasimfuad-have-you-tried-turning-it-off-154a938b`).

## The line

> Have you tried turning it off and on again? I have — three times, while you were talking — and honestly, we're both just staring at it now.

The line works because it twists the classic instead of repeating it: the agent asks the question, then confesses he already tried it three times while the customer was talking. The humour comes from his cheerful uselessness — not from the customer, who is never the butt of it — and the customer's desperation is felt in "while you were talking" rather than explained. It reads like one line a real support agent would actually say, and it stays tight at 139 characters.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
